## [Не выпущено]

### Добавлено
- Исходный код порта (`SuperminiReader_ESP8266/SuperminiReader_ESP8266.ino`) и файл `LICENSE` (GNU GPL v3).
- Скрипт `tools/img2code.py` — преобразование картинки в код 128×64.
- Новая схема подключения `wiring.png`.

### Изменено
- README переписан под реальное поведение прошивки: Wi-Fi включается долгим нажатием OK, устройство раздаёт собственную точку доступа и не подключается к домашней сети; полное описание управления, суфлёра и секретных кодов.
- Основа порта — оригинал версии 1.3.

### Исправлено
- Загрузка картинки: браузер отправляет ровно 1024 байта файлом вместо большой текстовой формы, которая не помещалась в ОЗУ ESP8266 («нужно ровно 1024 байта»). Страница показывает, сколько байт нашла в коде.
- Нажатие, разбудившее устройство из сна, больше не срабатывает как команда.
- Пространство имён `u8` переименовано в `utf8` (конфликт с типом SDK ESP8266).
- Пароль точки доступа на экране Wi-Fi больше не обрезается компилятором.

## Порт на ESP8266 (основа — оригинал 1.3)
- Библиотеки `ESP8266WiFi`, `ESP8266WebServer`, API LittleFS ESP8266, light sleep ESP8266.
- Пины: SDA=D2, SCL=D1, UP=D5, DOWN=D6, OK=D7.
- Меньшие буферы (`MAX_FILES`=40, `MAX_PAGES`=384, `MAX_MARKS`=16), HTML и CSS веб-страницы лежат во флеше.
- Чтение строк файла без таймаута ожидания в конце файла.
