## О проекте

Supermini Reader — компактное устройство для чтения текстов без телефона и компьютера. Тексты загружаются по Wi-Fi через встроенный веб-интерфейс и хранятся во внутренней памяти микроконтроллера. Читать можно прямо на OLED-экране, листая кнопками.

## Возможности

- 📟 Вывод текста на OLED-дисплей
- 🔘 Управление тремя кнопками: **UP**, **DOWN**, **OK**
- 🌐 Веб-интерфейс: добавление, редактирование и удаление текстов, индикатор прогресса чтения
- 📶 Настройка Wi-Fi через браузер; при отсутствии сети устройство поднимает собственную точку доступа
- 💾 Хранение данных во встроенной файловой системе LittleFS

| Устройство | Контакт | Пин ESP8266 |
|---|---|:---:|
| OLED | SDA | D2 |
| OLED | SCL | D1 |
| OLED | VCC | 3V3 |
| OLED | GND | GND |
| Кнопка UP | — | D5 |
| Кнопка DOWN | — | D6 |
| Кнопка OK | — | D7 |
| Все кнопки | второй контакт | GND |

> [!IMPORTANT]
> Дисплей питается от **3V3**, не от 5 В.

## Прошивка

Готовый образ: [`firmware/SuperminiReader_ESP8266.bin`](firmware/SuperminiReader_ESP8266.bin)

SHA-256:

```
47d84d3c54a70740ed0d415955123d1430fc547cb9e5c4149a6593b6b9139404
```

Проверка целостности: `sha256sum -c SHA256SUMS.txt` (из папки `firmware/`).

### Вариант 1. esptool (Windows / Linux / macOS)

```bash
pip install esptool
esptool.py --port COM3 --baud 460800 write_flash 0x0 firmware/SuperminiReader_ESP8266.bin
```

Вместо `COM3` укажите свой порт (в Linux — `/dev/ttyUSB0`, в macOS — `/dev/cu.usbserial-*`).

### Вариант 2. ESP Flash Download Tool (Windows)

1. Выберите чип **ESP8266**.
2. Добавьте `SuperminiReader_ESP8266.bin` с адресом **0x0**.
3. Укажите COM-порт и нажмите **START**.

> [!TIP]
> Если прошивка не стартует, сначала сотрите флеш: `esptool.py --port COM3 erase_flash`, затем прошейте снова.

## Первый запуск

1. Включите устройство. Если сохранённой сети нет, оно создаст точку доступа.
2. Подключитесь к ней с телефона или компьютера.
3. Откройте в браузере `http://192.168.4.1/`.
4. В настройках Wi-Fi укажите **SSID** и пароль вашей сети и сохраните.
5. Добавьте тексты через веб-интерфейс.

## Решение проблем

| Проблема | Что проверить |
|---|---|
| Дисплей пустой | Провода SDA/SCL (D2/D1), питание 3V3, I²C-адрес дисплея |
| Кнопки не реагируют | Второй контакт каждой кнопки подключён к GND |
| Не открывается `192.168.4.1` | Вы подключены именно к точке доступа устройства; отключите мобильный интернет на телефоне |
| Ошибка при прошивке | Другой кабель (с передачей данных), другой порт, `erase_flash`, зажать FLASH при старте прошивки |
| Не подключается к домашнему Wi-Fi | ESP8266 работает только в диапазоне **2.4 ГГц** |
