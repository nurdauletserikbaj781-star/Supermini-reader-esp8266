# Участие в разработке

Спасибо за интерес к проекту!

## Сообщить об ошибке

Откройте [Issue](../../issues) и укажите:

1. Модель платы и дисплея.
2. Версию прошивки (имя `.bin` и SHA-256).
3. Что вы делали, что ожидали и что получили.
4. Фото подключения, если проблема связана с железом.

## Предложить улучшение

1. Сделайте fork и создайте ветку: `git checkout -b feature/название`.
2. Внесите изменения и добавьте запись в `CHANGELOG.md` (раздел *Unreleased*).
3. Откройте Pull Request с описанием изменений.

## Прошивки

При обновлении `.bin` пересчитайте контрольную сумму:

```bash
cd firmware && sha256sum *.bin > SHA256SUMS.txt
```

## Если изменение касается оригинала

Если улучшение полезно всем, лучше предложить его и в [оригинальный репозиторий](https://github.com/razeb1t/Supermini-Reader).
